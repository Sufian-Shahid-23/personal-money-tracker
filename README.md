# Personal Money Tracker

A comprehensive personal finance tracker built in Excel/WPS Sheets.

## Features

- Income Tracking
- Expense Tracking
- Savings Goals
- Investment Monitoring
- Money Owed To Others
- Money Owed By Others
- Monthly Budgeting
- Financial Dashboard
- Net Worth Calculation

## Tools Used

- Microsoft Excel
- WPS Sheets
